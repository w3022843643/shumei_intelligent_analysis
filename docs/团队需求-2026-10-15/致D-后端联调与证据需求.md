## P0：MySQL 双端故障复验

使用独立测试库及当前 D 的 C store 适配器，按 E 正式答复中的步骤取证：

- 文件正确摘要但 JSON 片段/locator/版本与 C 不一致 → E `DependencyUnavailable`，不返回旧内存答案。
- 过期恢复和失败重试后，旧 lease 不能更新或发布，新 lease 能正常完成；重复写片段不增加重复记录。
- `activate_index` 与 `complete_job` 同一事务；注入完成失败后，活动索引和任务状态一起回滚。

报告包含版本、命令、异常类型、任务状态、attempt_no、活动索引及事务前后断言；不要在公开回执中贴 lease_token/凭据。E 的新隔离复跑已通过，但尚未替代你的 MySQL 证据。
