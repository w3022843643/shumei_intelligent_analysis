# 统一计数评测入口

日期：2026-10-15。`demo/benchmark_frames.py`复用E现有DM-Count计数器、P2PNet适配器和同帧比较器；本轮增加输入校验、命令行和报告，正式服务模型仍为dm_count。既有0.5.1发布包内容不重新生成，这些准备工具从仓库当前demo目录运行。

## 没有素材时

```powershell
python demo/benchmark_frames.py
```

空模板输出`blocked / awaiting_authorized_reviewed_frames`，退出码2；没有推理、MAE或补零。报告默认写入被Git忽略的`artifacts/frame-benchmark/report.json`。该结果是待验收清单，不是程序通过精度验收。模板及字段说明见 [素材与标注清单](录像素材与人工标注清单.md)。

## 先测 DM-Count

在vision依赖与官方权重已安装的环境中，复制manifest模板到`artifacts/evaluation/manifest.json`，放入获准PNG及真实标注，再运行：

```powershell
python demo/benchmark_frames.py --manifest ./artifacts/evaluation/manifest.json --output ./artifacts/evaluation/dm-report.json
```

默认权重为`artifacts/dm-count/model_qnrf.pth`，版本dm-count-qnrf-cc5f2132、SHA256 `16ef954a2cef40c66ee664f69273559553b735d5e2c9f90e2444f3c25dd45e05`，CPU 4线程。需要更改路径用`--dm-weights`；不匹配、不可加载或错误图像均报failed，不生成假预测。

文件摘要、唯一ID/图像/时刻、带时区时间、固定ROI、授权声明、独立复核及未解决标签均在推理之前检查。图像要求至少128×128，BGR解码转RGB；两个模型各自保留既有预处理。分场景报告保留小数估计、MAE、样本数、逐帧耗时和真实运行时/设备/线程/权重摘要；没有P2PNet时不生成其MAE。

## 加入 P2PNet 对照

需要核验P2PNet源码修订、权重版本/摘要及Python3.13可运行的架构构建器。已接收队长提供的SHTechA测试包并完成本机CPU推理，实际构建器、摘要和限制见 [队长测试包接收](队长P2PNet测试包接收说明.md)。上游修订、GPU和真实标注精度仍待验收；合成模型smoke也不代表官方模型已验证。

CLI的`--p2p-factory trusted_factory:build`指向本地受信任模块中的无参数函数，返回**未加载权重的torch.nn.Module**。构建器需由接收者按其核验过的源码适配；命令不自动下载源码、不代写未知官方签名。工具独立校验指定权重SHA256，用weights_only=True、CPU严格load_state_dict，支持raw state_dict及model/state_dict包装，再交给既有P2PNetAdapter。构建器不会从manifest读取，勿把未经审核模块作为factory。

```powershell
$env:PYTHONPATH=(Resolve-Path ./artifacts/p2p-runtime).Path
python demo/benchmark_frames.py --manifest ./artifacts/evaluation/manifest.json --output ./artifacts/evaluation/paired-report.json --p2p-factory trusted_factory:build --p2p-weights ./artifacts/p2p-runtime/verified.pth --p2p-sha256 填实际SHA256 --p2p-version 填真实权重版本 --p2p-source-revision 填已核验源码提交
```

P2P参数必须完整提供，否则报错。有效点需置信度严格大于0.5并在ROI内；不在测试集调阈值。报告分别保留DM-Count和P2PNet身份，不能用P2P推理却标成DM-Count。逐帧时间包含预处理、推理和ROI计数，排除模型加载；未预热，第一帧冷启动效应应在解释耗时时注明。

## 结果解释

成功运行状态为measured_pending_review，不自动关闭真实精度验收；人工授权真实性、留出独立性、场景覆盖、标签准确性和误差合理性仍须检查。缺失场景列在missing_scenarios中，不凑样本。data_kind=synthetic始终是流程验证。P2PNet_runtime_smoke_passed仅表示本次所提供模型跑通；P2PNet_project_compatibility_verified和真实计数/预测验收仍保留未确认，不能据一次运行宣布支持全部项目配置。

本轮已在合成空白RGB帧上跑通官方DM-Count权重和合成P2P模型的整条CLI，验证摘要、模型加载、相同帧ROI、误差计算和状态标记。该测试没有真实项目视频，也没有官方P2PNet精度结论。
