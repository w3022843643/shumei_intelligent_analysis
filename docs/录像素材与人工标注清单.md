# 录像素材与人工标注清单

日期：2026-10-15。目标为固定机位、固定ROI的camera_visible_people。当前没有获准真实评测样本；[manifest模板](fixtures/video-evaluation/manifest.template.json)保持空数组，不能据此生成真实MAE。

## 交付素材时需要什么

| 项目 | 提供者要填写的内容 |
|---|---|
| 使用授权 | 授权方、录像来源、允许本项目分析/存储/展示的范围和有效期、授权记录编号；使用说明与书面记录对应 |
| 资产身份 | D/C正式video/asset/source ID、原录像SHA256；测试阶段别名须注明未正式登记 |
| 固定机位 | camera_id、视角、画面分辨率、是否中途移动/变焦；发生变化须拆成新片段并重新确认ROI |
| 时间 | 真实录制开始/结束及UTC偏移、抽帧时刻；上传时间不能代替录制时间 |
| ROI | 一份归一化多边形，先冻结再标注；人物归属点规则和边界规则统一 |
| 场景覆盖 | sparse、dense、occluded、small_targets四类，记录各类实际数量；按冻结规则选择，不能只留表现好的帧 |
| 留出集 | 按录像/日期拆分训练、调参和最终holdout；相邻帧随机划分会泄漏，不用测试标签选权重/阈值/ROI |

建议先准备每类约20帧作为首轮排障目标，另准备同机位连续录像用于聚合和预测；20帧不是通过门槛，也不构成统计充分性保证。逐帧准确率样本与预测连续时序数据分别管理。正式算法已切换为P2PNet，当前只做该模型的人工误差验收，不再要求DM-Count对照。

## 人工标注步骤

1. 依据授权范围在本地抽取无缩放、无裁剪的PNG；计算文件SHA256，记录原video ID、SHA及带时区帧时间。默认计数业务每10秒抽帧，精度评测帧按预先冻结规则另选。
2. 一人逐个标记可辨认的人头中心并计数，ROI边界沿用半开射线规则：归一化方形左/上边界纳入、右/下边界排除；复杂多边形边界点先人工复核。该项目以人头位置近似可见人数，不能解释为人次或全景区在园人数。
3. 遮挡、模糊、只有身体而头部归属不明等记录uncertain_people，交给第二人独立复核；未解决的帧保留待标注，不填0。两人意见一致后填写整数manual_count、reviewed及标注修订号。建议同时保留点标注原件，当前评测命令消费已复核人数。
4. 用冻结的ROI、帧与复核标注评测P2PNet，不能看测试误差后重新选择ROI或阈值。计数估计保留小数；标签只允许非负整数。同一图像摘要、ID或帧时刻重复会拒绝。工具检查格式和声明，授权真实性、点位准确性及留出独立性仍须人工确认。

模板每个sample填写：id、scenario、file（相对manifest的POSIX路径）、sha256、source_video_id、source_video_sha256、recorded_at、manual_count、uncertain_people、annotator、reviewer、label_status。标注员与复核员使用不同别名，不必公开个人身份。存在样本时authorization_status必须confirmed。

```json
{
  "id": "camera01-frame0001",
  "scenario": "dense",
  "file": "frames/frame0001.png",
  "sha256": "填写实际64位小写摘要",
  "source_video_id": "填写真实录像ID",
  "source_video_sha256": "填写原录像实际64位小写摘要",
  "recorded_at": "填写真实带时区录制时刻",
  "manual_count": null,
  "uncertain_people": null,
  "annotator": "标注员别名",
  "reviewer": "另一位复核员别名",
  "label_status": "pending"
}
```

上面是待填表单，不能直接运行；null及pending会被拒绝，完成真实复核后再填数字和reviewed。不要拿示例字符串或空白当正式数据。

## 预测素材另需连续记录

固定5分钟完整窗取有效帧人数中位数，记录有效样本数及质量，缺失不补0、不循环短片。15/30分钟最低训练点12/24，还需足够的滚动回测前缀；当前实现至少17/32个完整连续点才能形成3折验证，仍不保证误差优于保持最新值基线。60分钟需更长的同机位多日连续数据，继续未开放。

正式验收保留模型/权重/ROI修订、授权、点位原件、人工分歧及裁决、逐帧误差、分场景MAE、样本数、耗时和设备。标注帧精度报告不能替代连续时序预测回测。运行说明见 [统一评测入口](archive/统一计数评测入口.md)。
