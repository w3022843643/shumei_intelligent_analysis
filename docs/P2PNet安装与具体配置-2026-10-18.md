# P2PNet 安装与具体配置：拉仓库直接接入

更新2026-10-18。用户已明确要求将运行所需模型源码、权重和测试材料一起上传GitHub。本文件替代此前“模型另发ZIP”的方式。E运行包仍0.6.2，业务源码与既有发布原件未重打。

## 1. 先拉取，运行统一入口

Windows安装Python3.13和Git，在终端执行：

```powershell
git clone https://github.com/w3022843643/shumei_intelligent_analysis.git
cd shumei_intelligent_analysis
powershell -ExecutionPolicy Bypass -File .\setup-p2pnet.ps1
```

已有副本先git pull --ff-only。脚本创建.venv，安装CPU版torch/torchvision及E的vision依赖，校验模型并运行自带短片。首次需要联网下载依赖，脚本未内置Python/第三方依赖安装包。CPU安装渠道参照 [PyTorch官方安装说明](https://pytorch.org/get-started/locally/)。

已有依赖时可用 `powershell -ExecutionPolicy Bypass -File .\setup-p2pnet.ps1 -SkipInstall`。

结果在`artifacts/clone-and-run/model-check.json`与`video-check.json`，不会改写仓库原始验收JSON。若某一步失败，脚本明确终止并回报错误，不伪造成功。

## 3. 固定运行配置

p2pnet、阈值0.5（严格大于）、PyTorch CPU、默认每10秒抽帧、完整5分钟取有效帧中位数。全画面ROI是安装示例，真实录像需要固定对应机位的ROI。缺测不填0，中位数保留小数，manual_validation未复核为null。

D公共HTTP的ROI形状由D映射为E内部points对象；配置JSON是E内部配置，不直接代替D公共请求。GPU/OpenVINO未开放；实际运行由模型校验器拒绝未验证设备，不自动回退DM。安装CPU版torch可避免原提供源码在CUDA可用时使用全局CUDA锚点。

## 4. D直接指向仓库里的模型

在D启动API/Worker的终端里，以实际E仓库绝对路径配置：

```powershell
$env:P2PNET_BUNDLE_DIR = (Resolve-Path ..\shumei_intelligent_analysis\model_bundle\p2pnet).Path
```

队友目录名不同时改成实际路径。API与Worker使用相同模型目录，保持可信服务端配置。D已经有P2PNetCounter.from_team_bundle(settings.p2pnet_bundle_dir)接线，不需要复制权重到D私有目录，也不接受客户端传Python路径。

独立核验可直接执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 demo/verify_p2pnet_bundle.py --output artifacts/manual-model-check.json
```
