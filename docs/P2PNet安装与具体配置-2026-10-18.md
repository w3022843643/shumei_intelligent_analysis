# P2PNet 安装与具体配置

日期2026-10-18。这是给队长和D的集中入口。E当前0.6.2；配置、加载器、核验工具已在Git仓库，收到的模型源码与权重另交本地模型包，不上传公共仓库。

## 1. 仓库里有什么

- [完整E内部配置JSON](../config/p2pnet-cpu.example.json)，可以直接读取并交VideoAnalysisConfig校验。
- [正式计数器](../intelligent_analysis/vision/p2p_counter.py)：校验7个源码文件和权重SHA，strict加载模型。
- [模型包核验脚本](../demo/verify_p2pnet_bundle.py)：不需要mytest.mp4；使用一帧合成图验证加载与CPU推理，不假称真实视频准确率。
- [E0.6.2 wheel及摘要](../release/README.md)、[完整服务契约](../E_SERVICE_CONTRACT.md)。

配置是p2pnet、leader-SHTechA-50604773、confidence_threshold=0.5（严格大于）、sample_interval_seconds=10、aggregation_minutes=5、pytorch、CPU、固定归一化多边形ROI。JSON中的全画面ROI只是安装示例，实际录像需要冻结对应机位ROI。不要把E内部ROI对象直接当作D公共HTTP数组；D映射按服务契约进行。

## 2. 安装E和推理依赖

在E仓库源码副本、目标虚拟环境中：

```powershell
python -m pip install -e ".[vision]"
```

使用已发布wheel时：

```powershell
python -m pip install "./release/shumei_intelligent_analysis-0.6.2-py3-none-any.whl[vision]"
```

依赖范围由pyproject.toml/包METADATA给出，不要求把队长旧requirement.txt整份覆盖当前环境。本机实际配置为Python3.13.13、torch2.14.1+cpu、torchvision0.29.1+cpu、numpy2.5.3、opencv-python5.0.0.93、Pillow12.3.0、scipy1.16.1；这是已测环境记录，不保证任意版本组合可用。新机器安装CPU版torch/torchvision并运行下一步核验；安装困难时回传错误和实际版本，不伪造已通过。

## 3. 放置单独交付的模型包

已整理可转交的本地文件：`artifacts/team-model-handoff/P2PNet-CPU-team-model-2026-10-18.zip`（79,828,899字节，约80MB）。ZIP SHA256：`7ec6444a529e3015cf9605f20538df0dba7e1650855fe039f318ad18f11d38d2`。

只含保持原字节的7个源码文件、权重及说明/摘要，不含视频。文件目录、摘要和CPU加载结果分别见 [交付清单](acceptance/P2PNet-team-model-handoff-2026-10-18.json)、[解压后核验](acceptance/P2PNet-portable-bundle-CPU-2026-10-18.json)。模型ZIP没有上传GitHub，需要用户单独转发；不是仅发仓库链接就自动取得模型。


本地模型ZIP展开后的目录名是p2pnet_bundle，复制到D的data目录，保持：

```text
api_platform/
  data/p2pnet_bundle/
    models/   （5个.py）
    util/     （2个.py）
    SHTechA.pth
    MODEL-RECEIPT.json
    README.md
```

D环境变量使用现有键：`P2PNET_BUNDLE_DIR=./data/p2pnet_bundle`。API和Worker应指向同一可信目录，建议部署时用绝对路径。模型目录不从客户端请求获得。路径是D私有配置，不公开到HTTP。

权重完整SHA256：`506047732b128ff09efef18e94bfacbe35fcfef300e5e9eeeece259b0488c63f`。收到源码标识为team-zip-2981dc75；没有独立核实上游提交或训练来源，不能称为已经核验的官方发行包。模型文件按队长原字节保留；本地包仅整理已提供材料供团队接收，不声称获得公开发布或商业使用许可。

## 4. 在E副本中核验指定模型目录

```powershell
python -X utf8 demo/verify_p2pnet_bundle.py --bundle "D模型目录绝对路径" --config config/p2pnet-cpu.example.json --output artifacts/p2pnet-machine-check.json
```

该命令成功才算这台机器完成配置/加载冒烟。缺权重、摘要不符、源码不符、配置错误和未验证设备直接失败。现有原模型源码在CUDA可用时存在全局设备选择，所以当前CPU构建器会明确拒绝CUDA可用主机；不能仅填CPU就声称GPU主机已验证，更不能自动回退DM。
