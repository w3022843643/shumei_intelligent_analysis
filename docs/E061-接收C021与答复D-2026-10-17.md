## 2. D 催办五项逐条答复

### ① 严格知识加载器

签名确认：`load_verified_knowledge_snapshot(cstore, ready_document_ids(), data_root)` 符合 E 预期，前提是文档列表已按当前用户权限过滤且仅包含可用活动文档。

D 负责提供 C store、DATA_ROOT、授权 ready ID 集及启动时绑定；E answer_message 每次调用 `knowledge_snapshot_loader`，再从严格校验后的内容构建检索索引。`from_payload` 本身不能核对 C 数据库，不能替代严格 loader。D 最新源码已按此绑定，无需在 E 内部另建数据库连接或再做第二套接线。

E 的实际测试/验收脚本有严格校验器调用点，不能仅凭 service.py 没有直接导入就认为校验器无用途。当前路径以正式启动绑定及运行证据判断；失败不得退回宽松快照或旧内存。

### ② 原文与索引版本耦合

这是 E 0.6.0 的服务入队缺口，本版已修复：

```python
index_document(file_path, metadata, *, index_version=None)
# metadata.document_version 原样取 C 登记值。
# 显式 index_version -> payload.version；省略则生成独立 e-index-<UUID>。
# worker 返回 document_version 与 index_version 两个独立字段。
```

D 不再按两者必须相等实现。同一原文可生成多个唯一索引版本，两者允许不同；各自必须与 C 对应记录一致。D 已有 v{n} 命名可以保留，不要求使用 E 的默认前缀。

**更正 E 10-15 回函中的格式表述**：原文版本按 C 登记字符串透传，不强制 `sha256:<完整64位摘要>`；C 本批使用过 `sha256:<32位前缀>`。文件 SHA256 完整性仍另外按完整64位验证，不能从版本标签推导完整文件摘要。

### ③ 视频入口、analysis_id 与 file_path

```python
analyze_video(video_id, e_native_config, *, analysis_id=None)
```

0.6.1 新增 D 指定的稳定 analysis_id，并核对 D 提交返回的 ID 未改变。未传时由 D 分配，兼容既有两个参数。E 先校验配置，再调用绑定的真实 submit_job；运行能力不支持时不得入队。

**file_path 不作为 API 请求或该服务函数的入参**。C021 正式路径由 D 在同一事务登记 queued job + visible analysis，领取 lease 后调用 `store.get_visible_input(analysis_id, lease)`，将其完整受检输入交给 E `process_video_job`。文件、时间、source_ids 不需要在 HTTP 创建任务时透传给 E。

D 已有“显式 validate_analysis → submit_job”同样是有效编排，先保留也可以；若改走本版 E 入口，仍由 D 做授权及 C 登记/事务。不能只升级 E 包就认为 D 的 C021 存储适配已完成。

## 3. 数值问答分支

成功要求 `metric/value/source_ids/period_start/period_end/queried_at` 六键齐全、非空来源，原样保留 metric_result，并生成 metric citation 和 used_metric_queries。C 参考工具的精确十进制字符串 value 原样保留。

不足必须明确 `status=metric_tool_unavailable`，不带 value/source_ids；E 返回空引用和空 used_metric_queries，不检索文档来补数值。0.6.1 已将不完整成功、无对象结果、或不足却携带成功字段映射为 DependencyUnavailable（D 映射 503），避免此前 ValueError 漏为 500。

已通过 C 官方参考只读适配器 + 隔离导入的真实资料核验合肥新桥机场 2025-01 的 **1,111,644 人次**，并验证 E metric_result、citation、used_metric_queries 与不支持粒度的不足分支。

该证据**不是 D resolver 成功证明**：D ee8b9f2 的 `metrics_query.metric_tool` 目前仍返回 data_source_unavailable，已复验其不足形状。请 D 推送 resolver 成功分支后回传提交号及真实请求体（实体 ID、粒度、时间范围），E 再复验 19 号真实 HTTP。摄像头人数仍不足，不能用机场值或文档历史数值替代。
